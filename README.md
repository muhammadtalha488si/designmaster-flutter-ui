designmaster-flutter-ui
A Flutter UI practice project where I worked on different types of real-world mobile app screens and tried to apply the concepts I learned while studying Flutter.

The main goal of this project was to understand and practice Flutter UI concepts by using them in one project instead of only learning them separately. I focused on building layouts, using widgets, working with reusable components, navigation, and responsive screen designs.

The project includes four sections: E-Commerce, Banking, Social Media, and Booking. Each section gave me a chance to practice different UI layouts and features while keeping the project focused on front-end development.

This project is mainly for learning and practicing Flutter UI. It does not include a connected backend or real transactions.
